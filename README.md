# 2dTarotCards
This is a 2d version of the python program in another one of my repositories made by instructing Claude.

<img width="997" height="823" alt="Screenshot 2026-10-25 at 3 10 14 PM" src="https://github.com/user-attachments/assets/025893b4-dd13-4d5d-ad1c-fc70a237cfd1" />

Download all three files and then cd to the folder in your terminal window.
~~~
zip -9 -r tarot.love . -x "*.DS_Store"
~~~
You have three other options, but I chose Gemeni because it appeared to have a free teir.
~~~
export GEMINI_API_KEY="your api key"
~~~

Launch the game from the terminal window you exported the api key from using the love2d app. This might look different on your system than mine.

You can find a love2d installer for your system here.
https://love2d.org/
